# 命令实现

## mkdir name

新建目录

1. 获取当前目录节点
2. 检查当前用户是否有写权限
3. 检查名称是否合法，且当前目录下没有重名项
4. 创建新的目录节点
5. 将新节点挂到当前目录的 `Children`
6. 更新目录修改时间



## cd path

切换目录

1. 支持 `/`、`~`、`.`、`..`
2. 虚拟文件系统内部统一使用 `/` 作为分隔符
3. 先根据路径解析目标节点
4. 检查目标节点是否是目录
5. 检查当前用户是否有读取权限
6. 切换当前工作目录



## touch filename

新建文件

1. 获取当前目录节点
2. 检查写权限
3. 检查文件名是否合法
4. 如果文件已存在，则只更新时间
5. 如果文件不存在，则创建新的文件节点并挂到当前目录



## vim filename [content...]

写入文件内容

1. 如果目标文件不存在，则先创建文件
2. 检查写权限
3. 如果命令后面直接带内容，则直接写入
4. 如果没有内容，则进入多行输入模式
5. 输入单独一个 `.` 表示结束
6. 写入后更新访问时间和修改时间



## more filename

查看文件内容

1. 解析文件路径
2. 检查节点类型是否为文件
3. 检查读取权限
4. 输出文件内容
5. 更新访问时间



## cp src target_dir

复制文件

1. 解析源路径
2. 只允许复制普通文件
3. 解析目标目录
4. 检查目标目录写权限
5. 在目标目录中创建一个新的文件节点
6. 复制源文件内容



## mv src target_dir

移动文件或目录

1. 解析源路径和目标路径
2. 检查目标是否为目录
3. 检查源父目录和目标目录写权限
4. 从原父目录删除挂载关系
5. 在目标目录中建立新的挂载关系
6. 更新节点父目录和修改时间



## tree [-d depth]

树形展示目录

1. 默认递归显示全部层级
2. `tree -d n` 可以限制层数
3. 输出时优先显示目录，再显示文件
4. 目录递归展开，文件直接输出



## rm [-r] name

删除文件或目录

1. 删除普通文件时可以直接删除
2. 删除目录时必须显式使用 `-r`
3. 根目录不允许删除
4. 删除前检查父目录写权限
5. 目录删除采用递归删除整棵子树
