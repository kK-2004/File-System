# 文件系统中的文件结构

当前版本的文件系统结构如下：

```txt
base
├── root
├── home
│   ├── user01
│   ├── user02
│   └── ...
└── etc
```

说明：

1. `base` 是虚拟文件系统的根节点
2. `root` 是 root 用户登录后的默认目录
3. `home` 下保存普通用户目录
4. `etc` 作为公共系统目录保留

登录流程：

1. 程序加载 `fms.pfs`
2. 读取磁盘中的用户列表
3. 校验用户名和密码
4. root 登录后进入 `/root`
5. 普通用户登录后进入 `/home/用户名`



## 磁盘文件结构

磁盘文件本质上是一个 JSON 文档：

```txt
fms.pfs
├── format_version
├── next_node_id
├── next_user_id
├── root_id
├── users
└── nodes
```

其中：

1. `users` 保存所有用户信息
2. `nodes` 保存全部目录和文件节点
3. 目录和文件通过节点 ID 建立关联



## 说明

用户密码直接保存在磁盘文件的 `users` 字段中，目录和文件统一由 `Node` 结构表示。
