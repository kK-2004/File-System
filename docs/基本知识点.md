# 基本知识点



## Node

一个 Node 包含：

1. `ID`：节点唯一编号
2. `Name`：文件名或目录名
3. `Type`：`file` 或 `dir`
4. `Parent`：父节点 ID
5. `OwnerID`：拥有者用户 ID
6. `Children`：目录下的子节点映射
7. `Content`：文件内容
8. `Created / Modified / Accessed`：时间信息



## Disk

`Disk` 表示整个虚拟文件系统的持久化状态。

主要包含：

1. `FormatVersion`
2. `NextNodeID`
3. `NextUserID`
4. `RootID`
5. `Nodes`
6. `Users`

整个结构最终会写入 `fms.pfs`。



## Session

`Session` 表示一次登录后的交互状态。

主要负责：

1. 当前用户
2. 当前目录
3. 命令读取
4. 命令执行
5. 磁盘落盘



## 路径规则

虚拟路径和宿主系统路径分离。

支持：

1. `/`：从根目录开始
2. `~`：从根目录开始
3. `.`：当前目录
4. `..`：上级目录

内部统一使用 `/`，不依赖 Windows 的反斜杠。



## 权限规则

当前权限模型比较简单。

1. `root` 可以访问和修改所有节点
2. 普通用户可以访问自己的节点
3. `home` 和 `etc` 这类公共目录允许普通用户读取
4. 是否允许访问统一由 `canRead` 和 `canWrite` 判断
